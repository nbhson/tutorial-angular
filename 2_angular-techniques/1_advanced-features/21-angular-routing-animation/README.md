# Routing Animation

> Demo gốc được sinh bằng Angular CLI v14. Các câu lệnh dưới đây đã chuẩn hoá theo Angular CLI v22 — xem [CLI Reference](https://angular.dev/cli).

## Development server

`ng serve` khởi động dev server tại `http://localhost:4200/`. Ứng dụng tự reload khi bạn thay đổi source.

## Code scaffolding

`ng generate component component-name` (viết tắt `ng g c`). Cũng hỗ trợ `directive|pipe|service|class|guard|interface|enum`.

## Build

`ng build` build ra thư mục `dist/`. Production build dùng `ng build --configuration production` — flag cũ `--prod` đã bị xoá từ Angular 15.

## Running unit tests

`ng test` chạy unit test bằng **Vitest** — mặc định từ Angular 21, thay thế Karma/Jasmine.

## Running end-to-end tests

`ng e2e` cần cài thêm package E2E (Cypress hoặc Playwright). Protractor đã bị loại bỏ khỏi Angular CLI.

## Further help

Dùng `ng help` hoặc xem [Angular CLI Reference](https://angular.dev/cli).
